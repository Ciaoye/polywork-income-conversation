# 你在做什么？怎么做？

线下「多元工作与多元收入聊天会」的本地互动网页。

它不是问卷：主持人提出一个问题，所有人先在手机上匿名回答，回答实时出现在投影端；大家可以点「想听展开」，主持人再从集体回答里选择线索进入现场谈话。

## 本地启动

```powershell
npm install
npm run dev
```

电脑上打开：

- 活动首页：`http://localhost:3000/`
- 主持 / 投影端：`http://localhost:3000/host`
- 参与者手机端：`http://localhost:3000/join`

## 让手机扫码加入

手机无法访问电脑自己的 `localhost`。现场时，需要让电脑和手机连接同一个 Wi-Fi，然后：

1. 查看电脑的局域网 IP。
2. 在电脑浏览器打开 `http://局域网IP:3000/host`。
3. 主持端二维码会自动变成手机可访问的网址。

也可以直接在主持控制台里修改二维码下方的参与者网址。

## 已有功能

- 9 道完整活动问题、引入文字与主持讨论提示
- 主持端切题，参与者手机自动跟随
- 匿名回答与修改自己的回答
- 开放文本、双文本、光谱、单选与组合题型
- 「想听展开」投票
- 主持人高亮、隐藏单条回答，或暂时收起全部回答
- 公网使用时用独立口令保护主持操作
- 回答与主持状态保存到本地 D1 / SQLite 数据库
- ciao os 风格的 Win95 灰色窗口、紫色标题栏与像素感控件
