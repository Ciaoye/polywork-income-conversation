# 你在做什么？怎么做？

线下「多元工作与多元收入聊天会」的互动网页。主持人在本机控制，参与者通过公网链接加入，不需要连接同一个 Wi-Fi。

它不是问卷：主持人提出一个问题，所有人先在手机上匿名回答，回答实时出现在投影端；大家可以点「想听展开」，主持人再从集体回答里选择线索进入现场谈话。

## 本地启动

```powershell
npm install
npm run dev
```

启动后，主持人在电脑上打开：

- 主持 / 投影端：`http://localhost:3000/host`

主持端不需要输入口令。它通过本机代理安全地控制公网活动，主持操作只接受来自 `localhost` 的请求。

## 参与者加入

把部署后的公网 `/join` 链接或主持端显示的二维码发给参与者。参与者可以来自不同网络，且无需注册。

参与者可自行浏览 1–10 题，并分别提交或修改每一题的回答；主持人切换投影题目不会打断参与者正在填写的题目。

## 已有功能

- 10 道完整活动问题、引入文字与主持讨论提示
- 主持端独立切换投影题目，参与者端可自由选择题目
- 匿名回答与修改自己的回答
- 开放文本、双文本、光谱、单选与组合题型
- 「想听展开」投票
- 主持人高亮、隐藏单条回答，或暂时收起全部回答
- 主持控制只在 localhost 开放，无需手动输入口令
- 回答与主持状态保存到部署环境的 D1 数据库
- ciao os 风格的 Win95 灰色窗口、紫色标题栏与像素感控件
